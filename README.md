\# Insurance Risk Analytics



\## Project Overview



This project analyzes insurance claim data to optimize marketing strategy and discover low-risk segments for AlphaCare Insurance Solutions (ACIS) in South Africa.



\## Quick Start



```bash

\# Clone repository

git clone https://github.com/yourusername/insurance-risk-analytics.git

cd insurance-risk-analytics



\# Install dependencies

pip install -r requirements.txt



\# Run EDA notebook

jupyter notebook notebooks/01\_eda.ipynb
